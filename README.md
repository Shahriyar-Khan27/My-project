# Responsive Website with HTML & CSS  

## 🚀 Project Overview  

This project is a **modern, responsive website** built using **HTML & CSS**. It includes:  

✅ **Navigation Bar**  
✅ **Hero Section**  
✅ **About Section**  
✅ **Projects Showcase**  
✅ **Contact Section**  
✅ **Footer**  

The design is **clean, user-friendly, and fully responsive**.  

---

## 🎯 Features  

### 🌐 Navigation Bar  
- Sticky **top navigation bar** with a logo and links.  
- Well-spaced **navigation menu** for easy access.  
- Smooth **hover effects** for better user interaction.  

### 🎨 Hero Section  
- A **gradient background** for a visually appealing look.  
- Includes a **large heading**, **brief description**, and a **call-to-action button**.  
- Optimized for **different screen sizes**.  

### 🏆 About Section  
- Provides a **brief introduction** with text and an image.  
- Uses **flexbox** for a clean, **responsive layout**.  
- Circular **profile image with a shadow effect**.  

### 📂 Projects Section  
- Displays multiple **projects in a responsive grid layout**.  
- Each project includes an **image, title, description, and button**.  
- **Hover effects** for a more engaging experience.  

### 📞 Contact Section  
- Includes **email, phone number, and social media links**.  
- Clickable links to directly **open email and call apps**.  

### ⚡ Footer  
- Contains **social media links** and **quick navigation**.  
- Styled with **hover effects** for smooth interaction.  

---

## 🛠 Technologies Used  

- **HTML5** → Structuring web content.  
- **CSS3** → Styling and layout design.  
- **Flexbox** → Creating responsive sections.  
- **CSS Grid** → Organizing project showcase.  
- **Media Queries** → Ensuring **mobile-friendly design**.
